# Chord Progression Player

Interactive chord progression player for songwriting practice.

**Live demo:** Open `index.html` in any modern browser (no build step, no dependencies).

## Features

- **Key & Scale picker** — any root (C–B) + Major / Natural Minor / Harmonic Minor
- **Common presets** — I–V–vi–IV, vi–IV–I–V, 12-bar blues, Andalusian cadence, minor progressions, and more
- **Editable sequence** — add diatonic chords, remove in edit mode, clear
- **Strum or Arpeggio** patterns
- **Tempo control** (40–180 BPM)
- **Looping** playback (toggle on/off)
- **Optional metronome**
- **Active chord highlight** with auto-scroll
- Clean dark music-app UI, mobile-friendly

## How to use

1. Choose a key and scale
2. Pick a preset or build your own progression
3. Select Strum or Arpeggio and set tempo
4. Hit **Play**

Audio is generated with the Web Audio API — works offline, no samples required.

## Tech

Single-file pure HTML + CSS + vanilla JavaScript. No frameworks, no npm.
